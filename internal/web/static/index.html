3 · My images 

    

      GET /images returns only rows where user_id matches the JWT subject.
      Log in as a second account and this list is empty.
    

    

    

  


  
  

    
4 · Resized variants

    

      The Temporal workflow fans out one resize activity per size in parallel, each writing back to
      {id}/{size} in object storage.
    

    

  


  
  

    
5 · Authorization probe

    

      Copy an image id from one account, log in as another, and request it here. Ownership is checked
      server-side against the JWT subject. It answers 404 rather than 403 on purpose — a 403
      would confirm the id exists.
